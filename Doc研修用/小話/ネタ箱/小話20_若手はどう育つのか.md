# 小話20　若手はどう育つのか ― 書けないが読める人材の話

|項目|内容|
|---|---|
|分類|⚠ リスク・マインド（議論を誘発するネタ）|
|尺|5分（スライド2枚）|
|推奨タイミング|クロージング前／最後の待ち時間|

---

## スライド1

### メインメッセージ
> **我々が「書きながら覚えた」道は、これから残るのか**

### 見せるもの

**掴み：正直な違和感**
```
 我々の育ち方
   先輩のコードを写経する
        ↓
   動かない → 悩む → 原因を探る
        ↓
   「なぜこう書くのか」が腹に落ちる
        ↓
   レビューで指摘されて、また覚える

 …この「悩む時間」を、AIが全部飛ばしてしまう
```

**若手が最初に触るものが変わった**

| | これまで | これから |
|---|---|---|
| 最初の仕事 | 簡単な画面を1本、自分で書く | **AIが書いた画面をレビューする** |
| 詰まった時 | 調べる・先輩に聞く | AIに聞く（即答が返る） |
| 得るもの | 手が動く／型が身につく | **判断の経験／全体像** |
| 抜け落ちるもの | ── | **「なぜ動かないか」を自力で追う経験** |

> 🤔 これは**退化なのか、順序の変化なのか**

### 話すこと
- ここは答えのない話です。皆さんの意見を聞きたいテーマとして持ってきました
- 私自身、写経して、動かなくて、半日悩んで覚えたクチです。その時間が一番身になった実感もある
- 一方で、**コンパイラが出てアセンブラを書かなくなった時も、同じ議論があった**はずなんです。何が本当に失われるのか、冷静に切り分けたい

---

## スライド2

### メインメッセージ
> **「書ける」の価値は下がる。「読んで判断できる」の価値は上がる**

### 見せるもの

**必要な能力の重心が移る**
```
 【減る】                    【増える】
 タイピング量               仕様を読み解く力
 API・文法の暗記            違和感に気づく力
 定型実装のスピード          影響範囲を想像する力
 ─────────────────────────────────────────
                            ★ 業務知識
                            ★ 設計意図を言語化する力
                            ★ 「これでいいのか」と問う力
```

**ただし ── 読めるようになるには、書いた経験が要る**

| 悩ましい点 | 現実的な打ち手 |
|---|---|
| 書いた経験がないと、レビューで違和感を持てない | **要所は手で書かせる**。全部AIにしない |
| 動かない時に追えない | **デバッグはAI任せにしない期間**を作る |
| 「なぜそう書くか」が育たない | AIの出力に対して **「なぜこうなっている？」と説明させる** |
| 全体像が見えない | **設計書からレビューまで通しで**経験させる（今日の研修の形） |

**育て方は変わるが、育たなくなるわけではない**
```
 ❌ AIに任せて、若手は監視だけ
       └ 判断の材料が育たず、いずれ判断もできなくなる

 ✅ AIを "いつでも聞ける先輩" として使わせつつ、
    ① 要所は自分で書かせる
    ② AIの出力を説明させる（読めているかの確認）
    ③ レビューに早期から参加させる     ◄── 従来より前倒しできる
```

### Take away
- 📈 **価値の重心は「書く」から「読んで判断する」へ**。皆さんの経験は、むしろ効いてくる
- ⚠ ただし**読む力は、書いた経験の上に乗る**。全部を任せる育て方は危うい
- ✅ **レビュー参加を前倒しできる**のは、AI時代の明確なメリット。早くから全体を見せられる
- 💬 これは**正解のない論点**。自PJでどう育てるか、持ち帰って議論する価値がある

### 話すこと
- 結論を出しに来た話ではありません。ただ、悲観だけで終わらせる話でもないと思っています
- **早い段階で全体像を見せられる**のは、これまでになかった利点です。従来は下流の一部しか任せられなかった若手に、設計からレビューまで通しで触らせられる
- 逆に気をつけたいのは、「AIが書いて、若手が眺めるだけ」の状態です。**判断の材料は、手を動かした経験からしか出てこない**
- 皆さんはどう思われますか ── 現場でどう育てるか、ぜひ持ち帰って議論してみてください
