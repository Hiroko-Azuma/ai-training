# 小話19　AIが得意な仕事・苦手な仕事

|項目|内容|
|---|---|
|分類|⚠ リスク・マインド|
|尺|5分（スライド2枚）|
|推奨タイミング|午前（全体像を掴ませたい時）／シミュレーションの前振り|

---

## スライド1

### メインメッセージ
> **判断軸は2つだけ ──「答え合わせができるか」「量があるか」**

### 見せるもの

**掴み：どこから任せればいいのか**

```
        量が多い・繰り返し
              ▲
   ┌──────────┼──────────┐
   │  △ 慎重に │ ◎ 最優先  │
   │           │           │
   │ 大量の判断 │ 定型実装   │
   │ 業務ルール │ テスト作成 │
   │ の適用    │ 移行・変換 │
   ├──────────┼──────────┤ ─► 答え合わせができる
   │  ✕ 向かない│ ○ 有効    │
   │           │           │
   │ 顧客との  │ 難所の調査 │
   │ 合意形成  │ 設計案出し │
   │ 曖昧な要望│ 障害の原因 │
   │ の確定    │ 切り分け   │
   └──────────┴──────────┘
```

**なぜこの2軸なのか**

| 軸 | 理由 |
|---|---|
| ✅ **答え合わせができるか** | 検証できないと、ハルシネーションを見抜けない（→ 小話05・07） |
| 📦 **量があるか** | 準備コスト（設計書・ルール整備）を回収できるかが決まる |

### 話すこと
- AI活用の相談で一番多いのが「どこから手を付ければ」です。この2軸で切ると、だいたい迷わなくなります
- 特に効くのが**「答え合わせができるか」**。コンパイル・テスト・実行結果で正誤が決まる仕事は、AIの得意領域そのものです
- 逆に、正解が誰にも分からない仕事 ── 顧客が何を欲しいか決まっていない、みたいな段階 ── ここはAIでは詰められません

---

## スライド2

### メインメッセージ
> **苦手なのは「知識がない」ではなく「正解を確かめられない」仕事**

### 見せるもの

**◎ 得意 ── 今日体験した領域**

| 仕事 | なぜ得意か |
|---|---|
| 設計書からの実装 | 仕様が定まっていて、コンパイル・テストで検証できる |
| テストコードの作成 | 観点さえ与えれば量産できる。実行結果で確認できる |
| 定型変換・移植 | パターンが決まっていて、量が多い |
| 既存コードの読解・説明 | 材料が全部そこにある |
| たたき台の作成 | 完璧でなくてよい。人が直す前提 |

**✕ 苦手 ── 人が持ち場を守る領域**

| 仕事 | なぜ苦手か |
|---|---|
| 暗黙の業務知識が要る判断 | **そもそも学習データに存在しない**（→ 小話05） |
| 曖昧な要望の確定 | 誰も正解を持っていない。決めるのは人 |
| 顧客・関係者との合意形成 | 責任を負う主体になれない |
| 正解を検証できないもの | 間違っても気づけない ＝ 一番危険 |
| 影響範囲の最終判断 | システム全体・運用・過去経緯を人しか知らない |

> ⚠ **危ないのは「苦手」ではなく「苦手なのに、それらしい答えが出てくる」こと**
> 検証手段がない仕事ほど、出力を疑う

**任せ方の順序**
```
 ① まず ◎ から。効果が見えやすく、失敗しても検証で止まる
 ② 次に ○。人が判断する前提で、たたき台を出させる
 ③ △ は、ルールと設計書を整えてから
 ④ ✕ は人がやる。ここを空けるために ①②③ を任せる
```

### Take away
- ✅ **判断軸は「検証できるか」「量があるか」**。この2つで自PJのタスクを仕分ける
- ✅ 得意領域から着手する。**効果が見え、失敗しても機械が止めてくれる**
- ⚠ 苦手領域でも**それらしい答えは出てくる**。検証手段のない仕事ほど疑う
- 🎯 AIに任せる目的は、**人が✕の領域に集中する時間を作ること**

### 話すこと
- 一番伝えたいのは最後の行です。**AIを入れるのは、人を減らすためではなく、人を難しい仕事に配置し直すため**です
- 定型実装やテスト作成に取られていた時間を、仕様の詰めや顧客との合意、影響範囲の判断に回す。そこは今もこれからも人の仕事です
- このあとのシミュレーションでは、**自PJのタスクをこの4象限に置いてみてください**。◎に入るものが多いPJほど、効果が早く出ます（→ 小話18）
