## スライド1

### メインメッセージ
> **「どのAIを使うか」より前に、「どの契約で使っているか」**

### 見せるもの

**掴み：「このエラーログ、そのまま貼っていいですか？」**
- 顧客のテーブル定義、実データを含むログ、社外秘の設計書
- ── 判断できますか？その根拠は言えますか？

**同じサービス名でも、入力の扱いは契約形態で変わる**

| | 個人利用の無料／一般プラン | 法人契約・API利用 |
|---|---|---|
| 入力の学習利用 | **される場合がある**（設定次第） | **されない条件が定められていることが多い** |
| データの保持 | 規約に基づき保持 | 契約で保持期間・削除が定められる |
| 管理者の統制 | なし | ログ管理・利用制限などが可能 |
| **判断のよりどころ** | 本人の設定と規約 | **会社の契約と社内規程** |

> ⚠ 上記は**一般的な傾向**。実際の可否は**自社の契約と規程が唯一の正解**
> → 「調べたら大丈夫って書いてありました」は根拠になりません

**そして、契約とは別に必ず効く制約**
```
 顧客との秘密保持契約（NDA）
        └ 「第三者への提供・開示の禁止」に、AIサービスへの入力が該当しうる
 個人情報の取り扱い
        └ 第三者提供・越境移転の観点
 プロジェクト個別のルール
        └ 顧客が「AI利用禁止」を明示しているケースもある
```

### 話すこと
- ここは正直、**AIの技術の話ではありません**。契約と規程の話です。でも一番事故が起きやすい所です
- ポイントは、**「AIが学習に使うかどうか」だけが論点ではない**こと。学習に使われなくても、**顧客の情報を外部サービスに送った事実**が契約違反になり得ます
- なので判断の順番は、AIの仕様 → ではなく、**顧客との契約 → 社内規程 → 使うサービスの契約形態**です

## スライド2

### メインメッセージ
> **迷ったら「入れない」「隠す」「聞く」**

### 見せるもの

**🚦 判断フロー**
```
 これをAIに入れたい
        │
        ├─ 顧客の情報／成果物か？ ──── Yes ─┐
        │        No                        │
        ├─ 個人情報を含むか？ ───────── Yes ─┤
        │        No                        │
        ├─ 社外秘・機密指定があるか？ ── Yes ─┤
        │        No                        ▼
        │                          ✋ そのままは入れない
        │                                  │
        │                    ┌─────────────┴─────────────┐
        │                    ▼                           ▼
        │              🎭 マスクする              📞 確認する
        │              固有名詞・実データを      PJリーダー／
        │              ダミーに置換して          社内の相談窓口へ
        │              構造だけ渡す
        ▼
 ✅ 入れてよい（社内の一般的な技術情報・公開情報・自作のサンプル）
```

**🎭 マスクの実務 ── 構造だけ渡せば、たいてい足りる**

| そのまま入れがちなもの | 渡し方 |
|---|---|
| 実データ入りのエラーログ | 顧客名・ID・金額をダミーに置換 |
| 顧客の設計書 | 固有名詞を外し、**構造・仕様の型だけ**を渡す |
| 本番の接続情報・鍵 | **絶対に入れない**（マスクの対象ですらない） |
| 顧客システムのソース | PJの取り決めを確認してから |

> 💡 AIに聞きたいことの多くは「**技術的な問題**」です。顧客固有の情報は、たいてい**なくても質問が成立します**

### Take away
- 🚫 **本番の認証情報・鍵・個人情報は、いかなる場合も入れない**
- ⚠ 「**学習されないから安全**」ではない。**外部に送った事実**が契約違反になり得る
- 🎭 多くの場合、**マスクして構造だけ渡せば目的は達成できる**
- 📞 **迷ったら入れずに聞く**。入れてから相談しても取り消せない

### 話すこと
- 一番覚えて帰ってほしいのは、最後の一行です。**入れてしまってからでは取り消せません**
- AIの操作ミスは戻せますが、これは戻せない。Gitで戻せない唯一の領域だと思ってください（→ 小話12）
- そして実務的には、**マスクすれば大抵いける**というのが救いです。技術的な質問に顧客名は要りませんよね。**この癖をつけるだけで、事故の大半は防げます**
