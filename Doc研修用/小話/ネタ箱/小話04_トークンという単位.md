# 小話04　トークンという単位 ―「日本語は高い」の理由

|項目|内容|
|---|---|
|分類|🔧 仕組み|
|尺|5分（スライド2枚）|
|推奨タイミング|CD実行待ち（小話02の後がつながりやすい）|

---

## スライド1

### メインメッセージ
> **AIは、文字でも単語でもなく「トークン」で世界を見ている**

### 見せるもの

**掴み：課金も、上限も、実は「文字数」で数えていない**

**トークン＝単語より少し細かい断片**
```
 英語   "unbelievable"  ─►  [ un ][ believ ][ able ]        3トークン
        "Hello, world!" ─►  [ Hello ][ , ][  world ][ ! ]    4トークン

 日本語 「書籍管理画面」  ─►  [ 書籍 ][ 管理 ][ 画 ][ 面 ]   4トークン
        「ヴァリデーション」─► [ ヴ ][ ァ ][ リ ][ デ ][ ー ][ シ ][ ョ ][ ン ]
                                                              8トークン
```
※ 分割のされ方はモデルごとに違う。珍しい語ほど細かく刻まれる

**同じ内容でも、言語でこれだけ差が出る**

| | 文字数 | おおよそのトークン数 |
|---|---|---|
| 英語 | 100語程度 | **約130** |
| 日本語 | 同じ内容 | **約300〜400** |

→ 日本語は**1文字で1〜2トークン**食うことも珍しくない
→ 「日本語は高い・上限に早く当たる」の正体はこれ

### 話すこと
- AIは文章をそのまま読んでいるのではなく、まず**トークンという断片に切り刻んで**から扱っています
- そして料金も、コンテキストの上限も、全部この**トークン数**で数えられています。文字数ではありません
- 日本語は不利です。同じことを書いても、英語の2〜3倍のトークンを使う。これは腕の問題ではなく仕組みの問題です

## スライド2

### メインメッセージ
> **「書いた量」がそのままコストと精度に効いてくる**

### 見せるもの

**桁感を持つ ── 今日のハンズオンのざっくり感覚**
```
 設計書1本を読ませる          数千 〜 1万トークン
 生成されたコード1ファイル      千 〜 数千トークン
 CDで1画面ぶんを作らせる       数万トークン（往復ぜんぶ込み）
 一日ハンズオンを回す          数十万〜 トークン
```
※ 正確な値はツールの表示で確認できる。**桁の感覚**を持つことが目的

**トークンは3か所に効いてくる**

| 効く先 | 何が起きるか |
|---|---|
| 💰 **コスト** | 入力も出力も課金対象。**毎ターン全部再送**なので、長い会話ほど二乗的に効く（→ 小話01） |
| 📦 **上限** | コンテキストウィンドウを食いつぶす（→ 小話02） |
| 🎯 **精度** | 情報が多いほど、肝心の指示が埋もれて薄まる |

**だから、こう書く**
```
 ❌ 前置き・経緯・感想を長々と書く
 ❌ 使わないファイルまで「念のため」読ませる
 ❌ 1つのセッションを一日引っぱる

 ✅ 必要な設計書を、必要な分だけ渡す
 ✅ 冗長な設計書はAIにとっても読みにくい（＝人間と同じ）
 ✅ 区切る。終わったら新しいセッションへ
```

### Take away
- ✅ **課金も上限もトークン数**。文字数ではない。日本語は割高だと知っておく
- ✅ 長い会話は、**毎ターン全部を再送している**ぶん想像よりずっと高い
- ✅ **簡潔で構造化された設計書は、コストにも精度にも効く**。冗長さは二重に損
- 💡 「たくさん渡せば賢くなる」は誤り。**必要なものを、必要なだけ**（→ 小話09 RAG）

### 話すこと
- 実務でいちばん効くのは「長い会話が高い」という感覚です。10往復目のやり取りは、1往復目の10倍近い量を毎回送っています
- そして意外と見落とされるのが**設計書の書き方**です。冗長な設計書は、コストも食うし、AIにとっても読みにくい。**人間が読みやすい設計書は、AIにとっても読みやすい**んです
- なので「AI用に特別な書き方をする」必要はありません。**簡潔に、構造的に**。それだけで両方に効きます

## 補足（質問が出たら）
- **Q. コードは日本語より安い？** → 英数字中心なので比較的効率は良い。ただしインデントや記号も1トークンを食う
- **Q. トークン数はどこで見られる？** → 多くのツールが使用量を表示する。研修中の画面でも確認できる
