# 小話05　なぜAIは、平然と嘘をつくのか

|項目|内容|
|---|---|
|分類|🔧 仕組み|

## スライド1

### メインメッセージ
> **AIには「原理的に知り得ないこと」がある**

### 見せるもの

**掴み：「明日の天気は？」と聞いてみる**
- 昔のAI　… それらしい嘘を答えた
- 今のAI　… ちゃんと正しく答える
- **何が変わったのか？** ← この答えが、ハルシネーションの正体そのもの

**まず、AIがやっている計算はこれだけ**
```
入力：「明日の東京の天気は」
        ↓
次に来る言葉の確率を計算
        ┌──────────────┐
        │ 晴れ    32%  │ ◄── ここから選ぶ
        │ 雨      18%  │
        │ 曇り    15%  │
        │ 　…          │
        └──────────────┘
        ↓
選んだ言葉を末尾に足して、また同じ計算　…を繰り返すだけ
```
→ 空を見てもいないし、気象庁も見ていない。**「それらしい続き」を選んでいるだけ**

**そして、知識には"断面"がある（知識カットオフ）**
```
   ────────── 学習データ ──────────┃          ？？？
   2020        2023        2025    ┃ ◄── ここから先は
                          学習の締切日 ┃      1バイトも知らない
                                    ┃
                              今日 ──┘
```

**素のAIが知り得ない領域は2つ**

| | 例 |
|---|---|
| ⏱ **学習の締切より後の出来事** | 明日の天気、先週リリースされたライブラリの新API |
| 🏢 **そもそも学習データに無いもの** | 自社の設計書、業務ルール、社内の命名規約 |

### 話すこと
- AIは、次に来る言葉の確率を計算して、それを1語ずつ並べているだけです。事実を調べているわけではありません
- しかも学習データには**締切日**があります。それより後のことは、原理的に1バイトも入っていない
- 明日の天気は、この2つ目に完全に該当します。**知っているはずがない**んです。……なのに、今のAIはちゃんと答えますよね？

## スライド2

### メインメッセージ
> **進化したのは「知らないと判断して、取りに行く」こと**

### 見せるもの

**今のAIが「明日の天気」に答えられる理由**
```
 ①「これは自分の知識の外だ」と判断する
        ↓
 ② Web検索という道具を使う          ◄── 小話03のエージェントループと同じ
        ↓
 ③ 取ってきた情報をコンテキストに載せる
        ↓
 ④ その情報を根拠に答える
```
→ **記憶から答えているのではなく、その場で取ってきている**
→ 今日の研修も同じ構造。AIは`Docsシステム/外部設計`を**読みに行っている**（＝社内固有情報を取りに行く行為）

**では、取りに行けなかったら？**

| 状況 | AIの振る舞い |
|---|---|
| ✅ 取りに行けた | 正しく答える（＝天気はこのケース） |
| ❌ 検索できない／情報源が存在しない | |
| ❌ そもそも「調べるべき」と気づかない | ➡ **それらしく埋める＝ハルシネーション** |
| ❌ 渡されていない（設計書を読ませていない） | |

**🚨 だから、ここを疑う**
- 社内固有のルール・命名（Web上に存在しない ＝ 検索しても出てこない）
- 新しい／マイナーなライブラリのAPI仕様（締切より後 or 情報が薄い）
- 具体的な数値・固有名詞・バージョン番号
- 長い会話の後半（渡したはずの情報が押し出されている → 小話02へ）

**🛡 嘘を潰す3層**
```
 ①与える     設計書・ルールをコンテキストに載せる（推測させない）
 ②機械で検証  コンパイル／テスト（存在しないメソッドはここで落ちる）
 ③人が判断    仕様と合っているか（機械に分からない所だけに集中）
```

### Take away
- ✅ **「AIは何でも知っている」でも「AIは嘘つき」でもない**。知らないと気づいて取りに行けたか、だけの違い
- ✅ 自社の設計書はWebを探しても出てこない。**渡さなければ、AIは埋めるしかない**（→ 小話10 spec駆動へ）
- ⚠ 一番危ないのは **「動いてしまう嘘」**。ビルドもテストも通るが仕様と違う ── これだけは人間しか気づけない（→ 小話15 レビュー観点へ）

### 話すこと
- 天気に答えられるようになったのは、AIが賢くなって天気を覚えたからではありません。**「これは自分では分からない」と判断して、検索する能力がついたから**です
- ここが数年でいちばん変わったところです。昔は「知らないことも、それらしく答える」しかなかった
- ただし、これで解決したのは**「Webで手に入る情報」だけ**です。皆さんの会社の設計書は、どれだけ検索しても出てきません
- だから今日のように**こちらから渡す**。渡さなければ、AIは天気を知らなかった頃と同じで、それらしく埋めるしかないんです
