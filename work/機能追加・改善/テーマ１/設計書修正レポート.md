DB物理設計:
- 物理名: `is_recommended`
- 論理名: おすすめフラグ
- 型: `BOOLEAN`（NOT NULL、デフォルト `FALSE`）
- 位置: `description`（概要）列の後、`created_at`（作成日時）列の前

## 1. 03ER図.md（DB設計）

### 目的
booksテーブルへの列追加をER図に反映し、テーブル定義書との整合性を保つため。

### 修正内容
- `books` エンティティに `BOOLEAN is_recommended "おすすめフラグ"` を追加（`description` の後、`created_at` の前）
- 改訂履歴に版数 1.2 を追加

### Before
```
books {
    ...
    TEXT description "概要"
    DATETIME created_at "作成日時"
    DATETIME updated_at "更新日時"
}
```

### After
```
books {
    ...
    TEXT description "概要"
    BOOLEAN is_recommended "おすすめフラグ"
    DATETIME created_at "作成日時"
    DATETIME updated_at "更新日時"
}
```

## 2. 04TBL定義.md（DB設計）

### 目的
booksテーブルの物理定義（列一覧・NOT NULL制約・CREATE TABLE文）に `is_recommended` 列を反映するため。

### 修正内容
1. テーブル定義表に `is_recommended` 行を追加（# 10、以降の created_at/updated_at の番号を繰り下げ）
2. NOT NULL制約の対象列一覧に `is_recommended` を追加
3. 「1. booksテーブル」節の `CREATE TABLE books` 文に列を追加
4. 「6. 全テーブル作成スクリプト」節の `CREATE TABLE books` 文（重複定義箇所）にも同様に追加
5. 改訂履歴に版数 1.3 を追加

### Before（テーブル定義表 抜粋）
```
| 9  | description | 概要   | TEXT     | NULL     | ... |
| 10 | created_at   | 作成日時 | DATETIME | NOT NULL | ... |
| 11 | updated_at   | 更新日時 | DATETIME | NOT NULL | ... |
```

### After
```
| 9  | description     | 概要       | TEXT     | NULL     | ... |
| 10 | is_recommended  | おすすめフラグ | BOOLEAN  | NOT NULL（デフォルト FALSE） | ONの場合、一覧画面のタイトル横に「おすすめ」表示 |
| 11 | created_at      | 作成日時   | DATETIME | NOT NULL | ... |
| 12 | updated_at      | 更新日時   | DATETIME | NOT NULL | ... |
```

### Before（CREATE TABLE文 抜粋）
```sql
CREATE TABLE books (
    ...
    description TEXT NULL COMMENT '概要',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '作成日時',
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新日時',
    ...
);
```

### After
```sql
CREATE TABLE books (
    ...
    description TEXT NULL COMMENT '概要',
    is_recommended BOOLEAN NOT NULL DEFAULT FALSE COMMENT 'おすすめフラグ',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '作成日時',
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新日時',
    ...
);
```

同一のCREATE TABLE文が「6. 全テーブル作成スクリプト」にも重複定義されているため、そちらも同様に修正した。

## 3. BK01_書籍一覧画面.md（画面設計）

### 目的
お勧めフラグがONの書籍について、一覧画面のタイトル横に「おすすめ」表示を行うようにするため。

### 修正内容
1. 一覧表示エリアの項目定義表「タイトル」欄の備考に、おすすめバッジ表示の説明を追記
2. 「おすすめ表示」の表示条件を明記した補足文を追加
3. 初期表示処理（3.1）・検索処理（3.2）のSELECT文に `お勧めフラグ` 列とOUTPUT一覧を追加
4. HTMLモック（BK01.html）にバッジ用CSS（`.badge-recommended`）と、サンプルデータ2件（リーダブルコード、達人プログラマー）へ「おすすめ」バッジ表示を追加
5. 改訂履歴に版数 1.1 を追加

### Before（項目定義）
```
| タイトル | title | text | ○ | クリックで詳細画面へ遷移 |
```

### After
```
| タイトル | title | text | ○ | クリックで詳細画面へ遷移。お勧めフラグがONの場合、タイトル横に「おすすめ」バッジを表示 |

**おすすめ表示:**
- 書籍のお勧めフラグ（is_recommended）がONの場合、タイトルの右横に「おすすめ」バッジを表示する
- お勧めフラグがOFFの場合は何も表示しない
```

### Before（初期表示SQL 抜粋）
```sql
SELECT
    書籍テーブル.書籍ID, 書籍テーブル.タイトル, 書籍テーブル.著者,
    カテゴリテーブル.カテゴリ名, 書籍テーブル.出版日,
    COALESCE(AVG(レビューテーブル.評価), 0) AS 平均評価,
    COUNT(レビューテーブル.レビューID) AS レビュー数
FROM 書籍テーブル ...
```

### After
```sql
SELECT
    書籍テーブル.書籍ID, 書籍テーブル.タイトル, 書籍テーブル.著者,
    カテゴリテーブル.カテゴリ名, 書籍テーブル.出版日,
    書籍テーブル.お勧めフラグ,
    COALESCE(AVG(レビューテーブル.評価), 0) AS 平均評価,
    COUNT(レビューテーブル.レビューID) AS レビュー数
FROM 書籍テーブル ...
```
（検索ボタン押下時のSQLも同様に `お勧めフラグ` をSELECT/GROUP BYへ追加）

### 画面イメージ
`img/BK01.png` を再生成。書籍一覧のタイトル横に赤色の「おすすめ」バッジが表示されることを確認済み。
